# Interactive API Reference

Swagger UI renders the contract from [openapi.yaml](openapi.yaml). See the [API guide](reference.md) for usage and examples.

The documented server, `http://localhost:5000`, is for local development on your own machine. There is no public API deployment documented. Browser calls from GitHub Pages cannot work with the service's current CORS configuration, and browser restrictions on local HTTP access may also apply. **Try it out is disabled**; use the guide's local Insomnia workflow to make requests. The UI below remains an interactive contract viewer.
